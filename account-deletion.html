바다낚시냥 계정 삭제 안내

바다낚시냥 계정과 연결된 서버 및 해당 기기의 사용자 데이터를 앱 안에서 직접 삭제할 수 있습니다.

계정 삭제가 완료되면 데이터는 영구 삭제되며 복구할 수 없습니다.

앱에서 계정 삭제하기

  1. 바다낚시냥에 로그인합니다.
  2. 로비의 설정 → 계정 삭제를 선택합니다.
  3. 1단계에서 계정과 게임 데이터가 영구 삭제된다는 경고를 확인하고 계속을 누릅니다.
  4. 2단계 입력란에 계정 삭제를 정확히 직접 입력합니다.
  5. 활성화된 계정 영구 삭제 버튼을 선택해 삭제를 완료합니다.
1단계 · 영구 삭제 경고→2단계 · “계정 삭제” 직접 입력

삭제되는 데이터

  • Supabase Auth 계정과 이메일 주소
  • 사용자 ID와 로그인 세션
  • 닉네임과 캐릭터 선택 정보
  • 프로필 이미지
  • 레벨·경험치·게임 내 재화
  • 인벤토리·장비·채비
  • 도감과 퀘스트 진행·보상 기록
  • 포획 기록과 랭킹 사용자 데이터
  • 게임 설정과 계정별 로컬 프로필
  • 낚시 시도, catch receipt와 중복 처리 방지 데이터
  • 건의·문의 및 커뮤니티 게시물
  • refresh token, 계정별 캐시와 미완료 요청 식별자

관리자가 작성한 공지사항은 서비스 공지 보존을 위해 남을 수 있지만 삭제된 계정의 작성자 식별자는 제거됩니다.

삭제 처리 방식

본인 로그인 토큰을 검증한 뒤 Supabase Storage의 프로필 이미지를 삭제하고 Supabase Auth 계정과 연결된 Database 사용자 데이터를 삭제합니다. 성공 후 해당 기기의 refresh token, PlayerProfile JSON, 요청 식별자와 이미지 캐시를 초기화하고 로그인 화면으로 이동합니다.

로그아웃은 계정 삭제와 다릅니다. 로그아웃하면 현재 기기의 세션만 종료되고 계정과 게임 데이터는 유지됩니다.
