개인정보처리방침

[개발자명](이하 “개발자”)은 모바일 게임 바다낚시냥 이용자의 개인정보를 중요하게 생각하며 서비스에 필요한 범위에서만 정보를 처리합니다.

앱명: 바다낚시냥시행일: [시행일]
인증이메일·비밀번호 및 Google 로그인을 Supabase Auth로 처리합니다.
보안비밀번호는 앱의 게임 DB나 로컬 프로필에 직접 저장하지 않습니다.
공개 정보랭킹의 닉네임·기록과 선택한 프로필 이미지가 공개될 수 있습니다.
계정 삭제앱 설정에서 서버 및 해당 기기의 계정별 데이터를 삭제할 수 있습니다.

1. 처리하는 개인정보 및 사용자 데이터

  • 회원가입·로그인: 이메일 주소, 이메일 인증 여부, Supabase 사용자 ID, 인증 제공자 정보
  • Google 로그인 선택 시: Google 계정이 제공하는 이메일 주소, 계정 식별자와 기본 프로필 정보
  • 게임 프로필: 닉네임, 캐릭터 선택, 온보딩 상태, 계정 역할, 선택적으로 등록한 프로필 이미지
  • 게임 진행: 레벨, 경험치, 게임 내 재화, 게임 설정, 현재 섬과 낚시 포인트
  • 게임 기록: 인벤토리, 장비와 채비, 도감, 포획 기록, 어종·크기·무게·등급·포획 시각, 랭킹, 퀘스트 진행과 보상 수령 기록
  • 안전한 처리와 복구: 낚시 시도·결과, catch receipt, 요청 식별자, 중복 구매·보상 방지 데이터, 생성·수정 시각
  • 이용자 작성 정보: 건의·문의 및 커뮤니티 게시물의 유형, 제목, 내용, 닉네임, 처리 상태와 작성·수정 시각

프로필 사진은 이용자가 시스템 사진 선택기에서 직접 고른 사진 1장만 접근하며 정사각형 JPEG로 처리합니다. 사진 라이브러리 전체를 수집하지 않습니다.

2. 개인정보 처리 목적

  • 회원가입, 이메일 인증, 로그인, 자동 로그인과 계정 보안
  • 캐릭터·프로필·게임 진행의 저장 및 복구
  • 인벤토리, 장비, 재화, 도감, 포획, 랭킹과 퀘스트 기능 제공
  • 중복 구매·보상 방지, 서버 판정 및 비정상 요청 방지
  • 프로필 이미지, 커뮤니티, 문의와 공지 기능 제공

3. 외부 서비스와 제3자 제공

서비스이용 범위처리 데이터
Supabase Auth이메일·비밀번호 인증, 이메일 확인, Google OAuth, 세션 관리이메일, 사용자 ID, 인증 정보와 세션
Supabase Database프로필과 게임 데이터 저장, REST/RPC 처리닉네임, 진행도, 인벤토리·장비·도감·포획·랭킹·퀘스트·설정 및 복구 데이터
Supabase Storage프로필 이미지 저장 및 제공이용자가 선택한 프로필 이미지
Supabase Edge Functions본인 확인 후 계정과 연결 데이터 삭제인증 토큰과 토큰에서 확인한 사용자 ID

Supabase는 인증·Database·Storage·Edge Functions 제공을 위한 처리수탁자입니다. Google 로그인을 선택하면 Google 인증 화면과 Supabase OAuth를 통해 인증되며 Google이 직접 처리하는 정보에는 Google의 개인정보처리방침이 적용됩니다.

개발자는 이용자의 동의가 있거나 법령에 근거가 있는 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다. Supabase에 전달되는 데이터는 광고 목적으로 제공되지 않습니다.

데이터는 서비스 이용 시 HTTPS/TLS로 Supabase 프로젝트에 전송됩니다. Supabase 인프라에서 처리되는 운영·보안 로그는 Supabase 정책과 프로젝트 설정에 따라 처리될 수 있습니다.

4. 비밀번호와 로그인 세션 보호

  • 비밀번호 인증은 Supabase Auth가 처리하며 앱은 비밀번호를 자체 게임 DB나 PlayerProfile JSON에 저장하지 않습니다.
  • Android의 refresh token과 Google OAuth verifier는 Android Keystore 기반 AES-GCM 방식으로 암호화하여 저장합니다.
  • 통신에는 HTTPS/TLS를 사용하며 Database 접근에는 사용자 ID와 Row Level Security를 적용합니다.
  • Service Role Key와 Google Client Secret은 앱에 포함하지 않습니다.

5. 다른 이용자에게 공개되는 정보

공개 랭킹에는 닉네임, 선택적으로 등록한 프로필 이미지, 어종, 길이, 무게, 포획 시각, 포인트, 등급과 낚시 방식이 표시될 수 있습니다.

프로필 이미지는 공개 Storage URL로 제공되므로 URL을 아는 사람이 조회할 수 있습니다. 타인의 개인정보나 민감정보가 포함된 이미지를 등록하지 마세요.

커뮤니티에는 닉네임, 게시물 유형·제목·내용·상태와 작성 시각이 표시될 수 있습니다.

6. 보유 및 삭제

  • 계정과 연결된 게임 데이터: 계정 삭제 완료 시까지
  • 프로필 이미지: 교체하거나 계정을 삭제할 때까지
  • 건의·문의와 커뮤니티 게시물: 개별 삭제 또는 계정 삭제 시까지
  • 로컬 프로필과 보안 세션: 로그아웃 시 세션을 삭제하고 계정 삭제 시 해당 계정의 로컬 데이터와 캐시를 삭제

계정 삭제 시 Supabase Auth 사용자, 연결된 Database 사용자 데이터, Storage 프로필 이미지, refresh token, 해당 기기의 계정별 PlayerProfile JSON, 요청 식별자와 캐시를 삭제합니다. 법령상 보존 의무가 있는 경우에는 필요한 항목만 분리 보관한 뒤 기간 종료 후 삭제합니다.

8. 앱 권한

  • 인터넷: 인증, 게임 데이터, 랭킹, 게시판과 프로필 이미지 송수신
  • 진동: 입질과 낚시 동작의 햅틱 피드백. 게임 설정에서 끌 수 있습니다.
  • 사진 선택: Android 시스템 사진 선택기를 통해 선택한 사진에만 일시적으로 접근하며 사진·미디어 전체 접근 권한은 요청하지 않습니다.

카메라, 위치, 연락처, 마이크와 알림 권한은 요청하지 않습니다.

9. 광고·결제·분석 SDK 현황

현재 앱에는 광고 SDK, 인앱결제(IAP), 별도 Analytics SDK 및 Crash reporting SDK가 포함되어 있지 않으며 해당 목적으로 개인정보를 수집하거나 제3자에게 전송하지 않습니다. 향후 관련 기능을 도입하는 경우 이 방침을 변경하고 필요한 동의와 안내를 제공합니다.
